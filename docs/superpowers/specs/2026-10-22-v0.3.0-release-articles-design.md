## 2. 事実(記事で使う数字)

すべて 1 台の Mac(Apple Silicon)と sasurahime v0.3.0 の実測。環境依存である旨を記事に書く。

- `scan`: 1 分 24 秒、Total reclaimable 28.3 GB
- 対話実行: 8 対象を選択、見積もり 21.3 GB、実測 17.8 GB、1 分 33 秒
  - uv 8.1 GB / cargo 4.9 GB / rustup 3.6 GB / app-support 1.5 GB / colima 1.4 GB /
    library-caches 1.2 GB(未選択)/ logs 545.4 MB / orphan-containers 6.1 MB
- scan の Tip から実行: Homebrew 2.9 GB、Playwright 1.4 GB、Claude 94.1 MB
- 対話実行後の Tip から実行: Microsoft Edge 1.2 GB、Obsidian 67.8 MB、Claude logs 1.9 MB
- 見送り: VSCode caches 423.2 MB、初回の Edge 1.2 GB
- 前後比較(スクリーンショット):
  - 使用済み 232.07 GB → 211.49 GB
  - システムデータ 135.35 GB → 114.11 GB
  - ゴミ箱 6.19 GB(実行後に出現)
- 削除の性質: uv / cargo / rustup は完全削除、app-support / orphan-containers はゴミ箱経由。
  ゴミ箱を空にするまで容量は戻らない

## 4. 共通ルール

- 文体: です・ます、落ち着いた技術文体。本文に絵文字は使わない

- 数字は上記の実測値に統一する。丸めは「約」を付ける
- 見出しは `##` まで。コードブロックは実行ログの引用に使う
- 相互リンクは各記事の末尾に置く。URL は公開後に確定するため
  `<!-- TODO: 公開後に URL を差し替える -->` を残す
- 文字種: CP932 で表現できる文字のみ。em dash と絵文字は本文で使わない
- 画像は Zenn へアップロードする前提で `images/...` を参照し、
  アップロード後に URL へ差し替えるコメントを冒頭に置く
